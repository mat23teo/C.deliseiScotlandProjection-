# Matteo's Dissertation about _Cetrariella delisei_ in Scotland
Matteo dissertation code for R plots, projections and analysis.  
Scripts contains two R scripts: one for the main code, one for the Svalbard 2013 timeseries data.  
Data contains all data used: maps, climate data, occurrence data.  
I began the project before connecting it to GitHub and so this is not a live repo linked to my R. I am just copying in the R code manually and the files that I have available to me. These scripts will not run as intended without downloading the files seperately, but all the raw code is there to inspect. 



Data from CHELSA-climate.org is too large (Geodata) to upload. Data is described in the paper.  
Within 'Data' in this repo you will only find files small enough to fit (25MB or less). These are the xlsx files such as occurrence data, svalbard 2013 climate timeseries data and maps.
